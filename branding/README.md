# CTRL+Z brand assets

The CTRL+Z logo is the exact in-app mark: an ember rounded square with a white **Z** and a
right-offset dash. The dark variant is the source used by the app, executable, installer,
window icon, header, and Settings.

- Dark accent: `#E06B3F`
- Light accent: `#CE5228`
- White: `#FFFFFF`

## Files

| Asset | Use |
| --- | --- |
| `ctrlz-app-logo-dark-1024.png` / `-512` / `-256` | Canonical app logo (dark accent). |
| `ctrlz-app-logo-light-1024.png` | Light-theme accent variant. |
| `ctrlz-app-logo.ico` | Windows multi-resolution icon (16–256 px). |
| `ctrlz-app-mark-white-1024.png` | Transparent white Z+dash mark for dark backgrounds. |

## Usage

- Use the dark 1024 PNG or ICO for app icons, store listings, and shortcuts.
- Use the transparent mark when the logo sits next to other branding.
- Keep clear space around the mark of at least the dash width.
- Do not stretch, rotate, outline, add gradients, or place the white mark on white.
