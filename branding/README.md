# CTRL+Z brand assets

The CTRL+Z mark is a white **Z with a dash above it** on the ember rounded square.

- Ember: `#CE5228`
- White: `#FFFFFF`
- Icon corner radius: 200 at the 1024 canvas size
- The dash is a separate rounded bar, not part of the Z.

## Files

| Asset | Use |
| --- | --- |
| `ctrlz-logo.svg` | Canonical scalable app icon. |
| `ctrlz-app-logo-dark-1024.png` / `-512` / `-256` | Exact in-app dark-theme logo (recommended). |
| `ctrlz-app-logo-light-1024.png` | Exact in-app light-theme logo. |
| `ctrlz-app-logo.ico` | Exact app icon, 16–256 px. |
| `ctrlz-app-mark-white-1024.png` | Transparent white Z+dash mark. |
| `ctrlz-logo-1024.png` / `512` / `256` | Full app icon on a transparent canvas. |
| `ctrlz-logo.ico` | Windows multi-resolution icon (16–256 px). |
| `ctrlz-logo-reference.svg` / `-1024` / `-512` / `-256` / `.ico` | Reference variant matching the supplied icon: right-offset dash, compact Z, `#E06B3F` square. |
| `ctrlz-mark-white.svg` + PNG | White transparent mark for dark backgrounds. |
| `ctrlz-mark-ember.svg` + PNG | Ember transparent mark for light backgrounds. |
| `ctrlz-mark-black.svg` + PNG | Black transparent mark for print/monochrome use. |

## Usage

- Use the full orange-square icon for app icons, avatars, and store listings.
- Use the transparent marks when the logo sits next to other branding.
- Keep clear space around the mark of at least half the dash width.
- Do not stretch, rotate, outline, or add gradients/shadows.
- Do not put the white mark on a white background; use the ember/black mark there.
