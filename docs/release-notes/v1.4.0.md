CTRL+Z 1.4 is the biggest update so far. Installs run in the right order, apps can be updated from one place, Windows tweaks come back after a reinstall, and the app speaks five languages.

## Installing your apps
- **Dependencies first.** Known runtimes, such as the Visual C++ redistributables, .NET and WebView2, are added and installed before the apps that need them. If a dependency fails, the apps that need it are not attempted, and the reason is shown.
- **Post-install commands.** You can run one command after an app installs. It runs without a shell, and the install preview shows it in full. Commands in a profile from another PC stay blocked until you review and approve each one on this PC. A command that matches a risky pattern asks again on every run. Examples are changing the firewall or the registry, adding an account, or downloading something.
- **Notes.** Each app can have a private note, shown when it fails or needs manual action. Notes are never logged, and they are left out of exports unless you ask.
- **Command line.** `ctrlz install`, `ctrlz dry-run`, `ctrlz list` and `ctrlz updates` work from a terminal on a fresh Windows install. They follow the same safety rules as the app.
- **Import a list.** My Apps can add apps from a `winget export`, a `scoop export` or a Chocolatey `packages.config`.

## Updates
- **Updates page.** See which installed apps winget can update. Update the ones you pick, or all of them; pinned apps stay out of **Update all**. You can also skip a version until a newer one appears.
- **Apps from GitHub releases.** CTRL+Z checks apps it installed from a GitHub release for newer versions. Portable apps get a Start menu shortcut.
- **CTRL+Z's own updates are safer.** A portable copy keeps the previous version until the new one has opened its window twice. If a new version fails to start, the previous one comes back automatically.

## Safety and reliability
- **Every installer is checked before it runs.** It is verified against its published SHA-256 where one exists. Its signature is checked too, and a broken signature stops the install.
- **Downloads resume after a dropped connection**, and the download of winget itself has a fallback mirror.
- **Verify a browser backup.** This reads every file in the backup and reports whether it can be restored, without changing anything.
- **Save diagnostics.** This writes a ZIP with paths and names removed, only when you ask. Nothing is sent anywhere.
- **Personal paths and your account name are kept out of logs.**

## After a reinstall
- **Tweaks.** Eight small, reversible Windows settings: file extensions, hidden files, opening Explorer to This PC, dark mode, taskbar on the left, no web results in Start, the classic right-click menu and fewer Start suggestions. Undo restores exactly what was there before. The tweaks you applied are saved in your profile, so the next reinstall can offer them again.
- **First-run guide.** A short welcome explains what to do before and after reinstalling.
- **Moving a profile to another PC.** Export tells you what needs attention there, such as installers stored on this PC or commands that will need review.
- **Restoring a browser that is not installed yet.** The restore offers to install it with winget first.

## Languages and accessibility
- **Five languages.** English, Arabic (laid out right to left), Spanish, Russian and German. Choose one in Settings → Language. Translations by native speakers are welcome; see CONTRIBUTING.md.
- **Screen readers.** Every control has a name a screen reader can read.
- **Keyboard.** Ctrl+1 to Ctrl+9 open the pages. Enter accepts and Esc closes every window.
- **Less motion.** Page animations follow Windows' *Animation effects* setting.

## Also
- **A smaller download.** The portable app leaves out framework files CTRL+Z does not use.
- **Uninstall can remove your data.** The uninstaller asks whether to also delete your CTRL+Z data; the default is to keep it.
- **Same privacy as before.** No account and no telemetry. Browser backups still never include passwords or cookies.
