CTRL+Z 1.5 makes updates safer for installed copies and the app easier to use for everyone: it now follows Windows contrast themes and text size.

## Safer updates
- **Installed copies can roll back.** Before the installer runs, CTRL+Z keeps a copy of the current version. If the new one closes before its window appears, or a later start never shows it, the previous version is put back and you are told why. Portable copies already had this. It protects updates made from 1.5 onward.
- **A version that failed is not offered again.** After a rollback, that version is skipped until a newer one is released.

## Accessibility
- **Contrast themes.** With a Windows contrast theme on, CTRL+Z uses that theme's colours for text, borders, buttons and selections. Turning it on or off applies at once.
- **Text size.** Windows' *Text size* setting (Settings → Accessibility) now scales every CTRL+Z window, and the window grows to match without leaving the screen.
- **Screen readers.** Narrator and other screen readers now read the sidebar pages and list rows by name, instead of an internal type name.
- **Small screens.** Every window fits the screen it opens on, so the bottom of the main window no longer hides under the taskbar on a small laptop screen. Windows on a second monitor stay there.

## Privacy and safety
- **Catalog refresh is your choice.** Settings → Installing has *Refresh the app catalog from GitHub automatically*, which is on by default. When it's off, the Catalog page downloads nothing until you press Refresh. It uses the copy saved on this PC or the one built into CTRL+Z.
- **Hidden characters are shown.** Before you approve a command from an imported profile, any invisible or text-direction characters in it, its folder or the app's name are shown as visible codes such as `‮`. Such characters could otherwise make the command look different from what runs.

## Fixes
- **Fewer unneeded runtimes.** Apps that bundle their own runtime, such as VS Code, Obsidian, Notion, IntelliJ IDEA, the Minecraft Launcher and PowerToys, no longer pull in .NET, Java or WebView2 when you install them.
- **Clearer scan results.** A program winget could not match now says *Not matched* instead of *winget*, and the reason is accurate when winget is missing.
- **Translated messages.** Match reasons, a few install messages and the update error messages that were still English are now translated. An update error still names the specific reason, so you can tell whether trying again can help. The catalog status and the folder shown with a post-install command are translated too.
- **Arabic layout.** App names, publishers and winget commands keep their own reading order inside Arabic pages: "7-Zip" no longer shows as "Zip-7", and "(x64)" keeps its brackets. The title bar keeps the profile name and the app count in order, and an Arabic app name in an English page reads correctly.
- **Dark mode tweak applies at once.** Turning on *Dark mode for apps and Windows* now switches open apps and the taskbar straight away, as Windows Settings does. Before, nothing changed until you signed out.
- **Command line.** `ctrlz version` (or `--version`) prints the version.
