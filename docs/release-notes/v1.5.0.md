CTRL+Z 1.5 makes updates safer for installed copies and the app easier to use for everyone: it now follows Windows contrast themes and text size.

## Safer updates
- **Installed copies can roll back.** Before the installer runs, CTRL+Z keeps a copy of the current version. If the new one closes before its window appears, or a later start never shows it, the previous version is put back and you are told why. Portable copies already had this. It protects updates made from 1.5 onward.
- **A version that failed is not offered again.** After a rollback, that version is skipped until a newer one is released.

## Accessibility
- **Contrast themes.** With a Windows contrast theme on, CTRL+Z uses that theme's colours for text, borders, buttons and selections. Turning it on or off applies at once.
- **Text size.** Windows' *Text size* setting (Settings → Accessibility) now scales every CTRL+Z window, and the window grows to match without leaving the screen.

## Fixes
- **Fewer unneeded runtimes.** Apps that bundle their own runtime, such as VS Code, Obsidian, Notion, IntelliJ IDEA, the Minecraft Launcher and PowerToys, no longer pull in .NET, Java or WebView2 when you install them.
- **Clearer scan results.** A program winget could not match now says *Not matched* instead of *winget*, and the reason is accurate when winget is missing.
- **Translated messages.** Match reasons and a few install messages that were still English are now translated.
- **Command line.** `ctrlz version` (or `--version`) prints the version.
